# NIGHTMIX DJ Studio

Touch DJ studio for modern browsers and iPad.

Serve public/ over HTTPS. No build dependencies. Audio processing stays in the browser.

Features: dual decks, scratch, waveform seeking, EQ, filters, crossfader, BPM matching, hot cues, loops and mix recording.

Limitations: no key lock or independent headphone cueing. Automatic BPM is approximate. iPad Safari device validation remains pending.
