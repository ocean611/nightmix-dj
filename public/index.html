从第一拍开始

  1. 点曲目右侧 A / B，将演示节拍或本地音乐载入唱盘。
  2. 按 ▶ 播放；拖动唱盘可以正向或反向搓碟，松手恢复原播放状态。
  3. 拖动波形跳转，CUE 返回起点；点 SET 后再点热 Cue 保存当前位置。
  4. SYNC 将本碟速度匹配另一碟并对齐估算节拍；自动 BPM 是估算值，可点 BPM 手动修改。
  5. 选择 1 / 2 / 4 / 8 拍循环；调节 EQ、滤波器及交叉推子进行混音。
  6. 点“录制混音”，结束后下载录音。建议用有线耳机或音箱降低延迟。

这是浏览器 DJ 工作台。速度与音调可独立调节；独立声卡预听与专业节拍网格编辑尚未提供。Safari 后台或锁屏可能暂停音频；演出时保持页面前台。录制格式取决于浏览器支持。
